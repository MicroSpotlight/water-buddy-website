0.1.1 BUILD 33 07.13
App Store 当前版本

让每一种语言和每一秒倒计时都跟得上

iPhone · Widgets · Live Activity

0.1.1 聚焦系统表面的语言一致性与实时状态更新，让 App 内的选择可靠地延伸到提醒、组件、实时活动和手表。

  • 语言选择贯通所有表面App、通知、主屏与锁屏组件、Live Activity 和 Watch 同步使用 App 内选择的简中、英文、日文或韩文。
  • 最新状态不被旧任务覆盖按顺序刷新通知与实时活动，避免较早的本地化任务覆盖刚刚更新的饮水量或提醒状态。
  • 下一杯倒计时持续前进Live Activity 与组件使用系统时间推进，分钟内也能保持及时、易读的下一杯状态。
  • 组件配置打开更稳定修复本地化环境下打开 Widget 配置时可能发生的崩溃，并补齐对应回归检查。
0.1.0 BUILD 33 07.12
App Store 首发版本

水滴伙伴，正式和更多人见面

iPhone · Widgets · Watch

首发版把快速记录、温柔提醒和系统组件整理成一套完整体验，并完成发布前的稳定性、隐私与多语言收尾。

  • 轻松记下一杯快速记录“喝一杯”或“小口补水”，设置每日目标，并在需要时撤回上一笔。
  • 提醒有节奏，也会休息支持本地提醒、专注结束后的可选补水提醒；达到目标后当天不再打扰。
  • 水位来到更多地方主屏与锁屏小组件、Live Activity 和 Apple Watch 都能查看进度或快速补记。
  • 为正式发布做稳完善数据迁移、跨日期状态、导航手势和多语言显示；饮水记录与偏好仍保存在本机。
0.1.0 BUILD 7 07.11
发布收尾测试

把发布前的控制权交还给你

iPhone · Widgets · Live Activity

这一版集中完成隐私、系统功能与提醒节奏的发布级收尾，也让小组件更接近真正的桌面水位卡片。

  • 目标完成，提醒休息达到每日目标后暂停当天后续提醒，第二天再恢复节奏。
  • 独立控制 Live Activity可以关闭锁屏实时活动，同时保留普通通知与小组件。
  • 隐私和数据操作更清楚集中说明本机数据与 Firebase 诊断，并完善撤回、重置和跨日期状态。
  • 组件铺满可用空间主屏组件采用更完整的全幅布局，修正预览尺寸和交互反馈。
0.1.0 BUILD 6 07.10
系统体验扩展

水位走出 App，来到手腕与锁屏

Apple Watch · Focus · Lock Screen

功能从 iPhone 页面扩展到更多系统表面，同时完成“水滴实验室”视觉重构与七套主题的深浅色适配。

  • Apple Watch 记录与同步在手表查看今日水量、目标和剩余量，也能快速补记一杯或一小口。
  • 专注结束后的可选补水通过 Focus Filter 在一次专注结束后安排轻量本地提醒。
  • 锁屏倒计时持续更新重做 Live Activity 和锁屏组件，让下一杯时间与今日进度更容易扫读。
  • 水滴实验室与七套主题首页、组件、通知和 Watch 统一卡通视觉，并完成深色模式适配。
0.1.0 BUILD 3 07.10
交互与兼容性

让第一套体验更像原生 iOS App

Navigation · Lock Screen

这个里程碑没有堆叠新页面，重点是把已有流程做稳：返回手势、目标边界和锁屏可读性都更符合系统习惯。

  • 原生边缘侧滑返回二级和三级页面保留主题返回图标，也支持符合 iOS 习惯的交互式侧滑。
  • 完成目标后仍可记录进度显示封顶于 100%，但真实饮水量仍能继续增加。
  • 锁屏对比度与安全区修正改善浅色、深色和不同渲染模式下的文本与水位可读性。
  • 发布配置补齐补充出口合规声明与稳定的 Bundle 配置，为外部测试做准备。
0.1.0 BUILD 1 07.09
第一个可用版本

先把“记下一杯”这件事做完整

iPhone · Widgets · Live Activity

水滴伙伴第一次形成完整使用闭环：从新手引导、快速记录，到提醒和系统组件，都围绕“今天”展开。

  • 喝一杯、小口补水与撤回用固定的 200 ml、100 ml 和撤回操作快速更新今日水量。
  • 每日目标与温柔提醒设置目标和提醒间隔，用本地通知维持自己的补水节奏。
  • 主屏、锁屏与实时活动不用进入 App，也能查看进度、下一杯状态或直接记录。
  • 四种语言与卡通主题支持简中、英文、日文和韩文，并提供 App 内语言与主题切换。
关于这些版本号

0.1.0 建立首个完整体验，0.1.1 集中完善本地化与系统组件稳定性。Build 代表构建里程碑，同一 Build 可在发布准备期间对应新的用户版本；日期来自版本配置与 Git 历史。
